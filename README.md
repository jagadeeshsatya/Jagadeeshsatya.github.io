# Satya Jagadeesh Kodela — Portfolio

This is the refreshed GitHub Pages portfolio, retaining the original dark background, green terminal accents and monospace styling.

## Files

- `index.html` — complete responsive portfolio website
- `assets/Satya_Jagadeesh_CV.pdf` — CV download and preview
- `assets/Satya_Jagadeesh_Cover_Letter.pdf` — general cover-letter download and preview

## Publish to GitHub Pages

1. Download and extract this ZIP.
2. Open your existing portfolio repository: `https://github.com/jagadeeshsatya/jagadeeshsatya.github.io`
3. Replace the repository's existing `index.html` with this updated `index.html`.
4. Upload the complete `assets` folder, keeping both PDF files inside it.
5. Commit the changes to the repository's publishing branch (usually `main`).
6. Wait for GitHub Pages to deploy, then check `https://jagadeeshsatya.github.io/`.

**Important:** Keep the folder structure exactly as provided. The PDF links in the website expect the files to be inside `assets/`.

## Before publishing

- Check that the CV and cover letter PDFs are the versions you want recruiters to download.
- The project cards intentionally do not contain GitHub repository links yet. Add links when each repository is ready to share.
- The Forage entries are labelled as virtual job simulations, not employment internships.
- No profile photograph or unsupported certification claims have been added.
- The Master's degree is described as expected to be completed in December 2026, matching the supplied CV.

## Updating projects later

When a project repository is ready, edit its card in `index.html` and add a link to the public repository or a project detail page. Only publish screenshots, logs and research material that are safe to share and do not expose private data or confidential evidence.
